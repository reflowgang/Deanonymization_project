If I was building a NAS, I wouldn't use a RasPi. The USB and network controllers use the same bus, so your performance lags either way.  I built mine with a Banana PI that has SATA and GB Ethernet.  But if you're going to stick with the RasPi, use drives that have their own power supplies, as the RasPi's USB ports can't supply enough power to run some of the larger capacity external drives.  RasPi is also restricted to USB2.x, so if you find USB2 drives at a lower cost, go with those.  I'd also recommend you take a look at OpenMediaVault for the Pi. It supports many of the things you're looking for with a nice GUI front end so that you won't need to learn a lot of *nix to get it going.
