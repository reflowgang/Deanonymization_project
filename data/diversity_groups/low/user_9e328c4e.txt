I'm not advocating it, but it is technically possible to make something in UE4, or Unity with the right plugins, without particularly doing any programming. You'd need to work within the confines and limitations (and flaws) of whatever GUI system you were using, though, and knowing enough to be able to write at least some simple code would probably make things a lot easier even then. Starting with learning some code (the basics at least) seems like a good idea to me, but it's very difficult to learn from scratch without being able to do anything practical. Once you're familiar with one language you can basically sit down with a book and learn another in many cases, but when starting out, make sure you're at least set up to output text so you can mess about and see results when you want to. I don't know about UE4, but many Unity tutorials try to teach basic programming at the same time as the editor stuff. That may provide a reasonable way for you to be able to test what you write.
