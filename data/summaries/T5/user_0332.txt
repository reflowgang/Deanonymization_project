If you plan to implement an optimization, I recommend a pointer propagation. This is very simple and still lots of optimizers ignore it. For example, mem += 3; while (mem[0]) { mem += 1; mem[0] -= 1; mem += 1; } mem -= 4; mem[0] = 0; becomes: while (mem[3]) { mem[1] -= 1; mem += 2; } mem[-1] = 0; mem -= 1; /* you can safely ignore this at the end of file */ where every relative memory access has been adjusted.
