If I'm understanding how this works, you can use AutoHotKey to do things like this. It's a powerful program for creating scripts to automate things like inputting text, hitting key strokes in sequence with time delays, run programs, etc. that can be bound to any key or key combo. It runs independently of the game on your PC in the background so there should be no EULA issues... it just automates what you would normally do manually. I use it in hyper-realistic games like IL-2: CLOD with the Team Fusion patches to automate tedious complex things like getting ready for take-off. I don't use it in WT but would if manual engine management was worth the trouble to me. Anyway, you should, for example, be able to make a script that runs from a key bind not used by the game, reads data from http://localhost:8111/, copies it into your clipboard, types T, inputs your message, CTRL-V to past in the data and hit ENTER to execute these key commands for you. If reading the http://localhost:8111/ data isn't possible, you could wing it by just assigning something simple that can be done with one hand to output text such as SHIFT-1 = "I need halp! (1,000m alt)", SHIFT-2 = "I need halp! (2,000m alt)", and so on. Hope this helps!
