i've seen few that didn't have the option. There have been quite a few reasons to disable it, enough to warrant the option too... Almost no one needs to worry about though.. if you do need to.. you probably bought a CPU with out hyper-threading anyway ;-)
now days not really, though there still maybe some fringe apps/servers that perform better with out it. Hyper-threading doesn't add more cores, it uses one core to do different types of instructions. So if you are constantly sending the same instructions to the core it will only use the one hyper-threaded virtual core. Now days hyper-threading, OS's and applications have evolved a bit so its not as of a big deal at all but in the early days of hyper-threading disabling hyper-threading or a CPU with out hyper-threading would give you better performance in those situations. MySQL was a good example of the hyper-threading debate.
